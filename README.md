# Blablafal - Car Sharing per Fiato ai Libri

Progettazione e sviluppo di una piattaforma web funzionante per la gestione del car-sharing legato al festival "Fiato ai Libri". 

*Nota: Il codice sorgente di questo progetto è mantenuto in un repository privato per motivi di sicurezza e privacy legati all'ambiente di produzione.*

🌍 **Visita il sito live:** [https://fiatoailibri.it/blablafal/](https://fiatoailibri.it/blablafal/)

**Tecnologie utilizzate:**
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Hosting & Gestione: Altervista
